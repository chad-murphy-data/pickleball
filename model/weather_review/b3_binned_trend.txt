# B3 part 3 — is the outdoor binned skill compression a dose-response?

Pre-specified before looking: SIGNAL requires (a) a negative binned
trend slope whose cluster-bootstrap CI excludes 0, (b) an outdoor
top-bin drop that the INDOOR arm does not reproduce, and (c) a top
bin that is not one tournament in disguise (leave-one-out stable).
Any one of those failing downgrades it to a composition artifact.

## 5. what the binned-trend interval still allows (20 mph vs 2.5 mph calm)

Applying the T1 outdoor trend to a game to 11 (race DP, web/sitelib/race.py):

       point -0.0258: effective skill slope x 0.909
          65% favorite -> 63.7% (-1.3 pp)
          75% favorite -> 73.0% (-2.0 pp)
          90% favorite -> 87.8% (-2.2 pp)
    CI floor -0.0568: effective skill slope x 0.799
          65% favorite -> 62.1% (-2.9 pp)
          75% favorite -> 70.5% (-4.5 pp)
          90% favorite -> 84.8% (-5.2 pp)
     CI ceil +0.0073: effective skill slope x 1.026
          65% favorite -> 65.4% (+0.4 pp)
          75% favorite -> 75.5% (+0.5 pp)
          90% favorite -> 90.6% (+0.6 pp)

MDE of the continuous outdoor interaction: se(advw) ~ 0.0157, so the
80%-power / 5%-two-sided minimum detectable |d| is 0.044.  At 20 mph that
is an effective skill slope x 0.825 = -2.5 / -3.9 / -4.5 pp for a
65 / 75 / 90 percent favorite.  Anything larger than that would have been
caught; anything smaller would not.
